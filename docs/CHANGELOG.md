## 2026-11-05

- **What:** Batch 3: the privacy lock and Reading mode. **Lock:** a page, notebook or database can be locked (page ⋯ menu, notebook Tab options, database ⋯ menu, ribbon File › Protect); the lock screen replaces the content, which is never loaded or drawn. Ways to unlock, chosen in the new Settings › Lock: Face ID / Touch ID / Windows Hello (WebAuthn platform passkey, `userVerification: required`, only the credential id kept on the device), a 4–6 digit PIN and a password (salted PBKDF2-SHA-256 hashes in the `settings` table, so backups carry the lock settings). Plain words everywhere: a privacy lock, not encryption. Forgot: device check, or a ticked and honest "Remove the lock". It locks again on leaving, on hide or close (the screen is blanked at once) and after 5 idle minutes (1–30 in Settings). Hidden from search (title with a 🔒 only), Review, Recent, Favourites, sidebar text and Calendar. **Reading mode:** the 📖 Read part of the switch turns the page into Reading mode in place (Read tools, progress with minutes left, ruler, panels) or opens a full-screen reader (controls on a tap in the middle, edge taps and swipes turn pages in paged mode); chosen in Settings › Reading, both always available. Themes (Same as the app, Day, Night, Sepia, Paper, Dark contrast), fonts (incl. OpenDyslexic), size, line spacing, margin, width, scroll or pages, line focus or ruler, resume and bookmarks per page and device, an outline of the headings, highlight while reading (saved, with Undo), Lock to reading, "always open in Reading" for a page or notebook, read aloud with the Web Speech API (word marks, speed 0.5–2×, device voices, read from a tap, on into the next page, sleep timer 10/20/30/60), blanks softly marked with a Self-test switch. Extras: reading streak, Look up a word, keep the screen awake. The Read set tools and the ribbon View items that said "coming" are real; the control panel lists them.
