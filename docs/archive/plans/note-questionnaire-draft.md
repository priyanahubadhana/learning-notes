# Start questionnaire for making notes: draft (owner, 16 Nov 2026)

Status: draft, in design with the owner. Becomes part of a combined user story later. Builds on existing app parts: page tabs (Notes, Summary, Mind map, Slides, Audio & video, Review), recall cards, databases, tags, presets, Blank (tap to reveal), paper pages.

## The questions (asked before notes are made; tap to pick)

1. **Why are you making these notes?**
   - **Understand and recall** (default): a study book, more advanced than a book. Summary and notes to read through, slides, recall cards, a full mind map made by Claude (default), plus an optional **recall mind map** the user builds from memory, part of the recall features, all visual.
   - **Keep as a knowledge backup**: a database to look things up in later.
   - **Other**: the user types it.
2. **What is important to you here, and how important is it?** One question: the user names the part that matters (or "all of it") and picks a level: Must master · Important · Nice to know (owner OK 16 Nov). This sets how deep the notes go and how many recall cards are made.
3. **Where should it go?** A new notebook, or an existing one (pick it).
4. **Tags:** use the suggested ones, select existing ones, or type new ones.
5. **How should it be written?** (also asks how proficient the user is)
   - **Easy**: simple words anyone can follow.
   - **Hard**: the correct terms, each one explained; tapping a term shows a dictionary-style meaning.
   - **Other**: the user types it.

## Remembering answers

- The answers are kept for this note.
- A preset in Settings saves a set of answers so the questions can be skipped next time.

## Where it runs

First in Claude Code as a test (Claude asks before making notes); later as a screen in the app.
