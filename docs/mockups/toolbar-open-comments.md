# Toolbar mock: OPEN owner comments (11 Nov), each must be applied in toolbar-mock-v5.html

T1. Shapes & aids tab: every tool sits on one long scrolling layer, so the owner has to scroll again and again on iPad. Divide it into organised groups instead of one strip.
T2. Pen options order: Type ▾ (ONE pen chip with ▾: ball pen, brush pen, pencil, marker, highlighter) → Size ▾ → Colour (3–4 visible + ▾ for all) → Feel → the rest in the order given earlier → Line ▾ (pick one) → Page/line/dotted/grid inside a ▾ (low value, but keep them).
T3. Text "Box" section: "Box" comes first, ONE setting (1 / 2 / 3 styles) chosen via ▾, with a settings button in front of it.
T4. Paper size A4: the grid and paper style must stay visible when A4 is chosen (it currently drops them).
T5. Text and Pen each get their own dedicated bar (Text bar: box style and layout, Aa font/size, headings, every list type: bullet, star, numbered, checklist; Pen bar: types, colours, sizes, favourites). Shapes & edits come out of Pen and get a top-bar slot with all their options. No duplicated controls between pill and card. Eraser, Lasso, Insert etc. stay.
T6. The Text row gets headings H1–H3, lists, B/I/U/S, indent/outdent/alignment, callout/divider/inline code.
T7. Cards are a layer: a tap, drag or scroll inside any card never reaches the page. The first tap outside an open card only closes it. Card buttons keep the text selection.
T8. More menu: full rework into the card pattern (header, ✕/minimise, glass, sections by purpose: View / Write & input / Page / Layout & settings, icon + name + one line each, switches and tiles); merge duplicates. The same goes for every leftover menu/sheet (Duplicate/Copy/Cut/Delete/Turn into menu too).
T9. Text box resize dots sit further from the text, so placing the cursor near the edge doesn't grab a handle.
T10. Pressing the box grip/move tab drops the typing cursor at once, so dragging never types.
