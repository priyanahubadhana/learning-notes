# Toolbar v6: owner comments (12 Nov) + my own findings
V1. Settings in cards change things instantly with no feedback. Tap applies VISIBLY: the changed part glows briefly; new bars/items slide or fade in; toast "X turned on · Undo"; each row has a tiny live preview (app-wide rule).
M1 (mine). The Box card opens over the selected text box: anchor it to the side away from the box.
M2 (mine). The text box's own mini-bar has a second big minimise button: remove it.
M3 (mine). The top-bar "Done" may be a leftover: remove it if it has no purpose (Home had the same).
V2. Professional: a '+' at the end of every tool row (Text, Pen, Eraser, Shapes, Lasso) opens a picker of every setting from that tool's cards; picked items pin onto the row; drag to reorder, rename, remove, group labels (like the customisable tabs). Beginner unchanged. Keep the row single-line: overflow goes into a '⋯ more pinned' ▾, never sideways scroll.
V3 (owner, 12 Nov, on v7). Same premium card look for the All tools panel, the selection/lasso bar (Cut/Copy…), the text-box bar, and every remaining menu/setting still on the old style (audit them all).
V4 (owner). "Custom tools" (Professional only), replacing the separate '+ pin' idea:
 - One ★ tap (in any tool row) saves the CURRENT setup as a custom tool: any mix across tools (e.g. fountain pen + thickness + colour, or box look + border + font + size; eraser setups too).
 - On save, a sheet asks: name, icon/preview, and WHERE to place it (which row: Text / Pen / main bar / any tool row) and position, with a live preview of the toolbar layout.
 - Custom tools show as one-tap buttons with a tiny preview; Edit mode: reorder (drag), rename, change contents, remove; a Presets list to manage them all.
 - Beginner: hidden (unlockable via Professional features).
