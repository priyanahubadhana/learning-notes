Owner's answers below decide which path it was.

A box made with the + box icon, and a box made then pasted into from the box bar, looked the same as the plain one. Yes: every new box, the first one included, starts with the style. Yes: old pages keep their first box as it is (no repair of old notes).
- **Fix:** part C0-1 in lane B (`slice/c0-1-box-style`, ln-2a14), started 20 Nov; a test per way of making a box (tap, top of page, +, Enter, paste, phone order).

## C0-2 Paste ▾ in the top row cannot be tapped with the Pencil (item 1)

- **Saw (18:35):** with the typing cursor in a box, a Pencil tap on Paste (and on its ▾) in the tool row does nothing. With a finger it works.
- **Expected:** a Pencil tap pastes at the cursor and the cursor stays in the box; ▾ opens the paste formats.
- **Trace (owner's recorder, 18:36):** eight Pencil taps on the button (x 572–614, y 165–177): each one gives touchstart (stopped with preventDefault by our own code) → pointerup → touchend, with **no click** afterwards. The finger taps give mousedown → click. So the button waits for a click that a Pencil tap never produces there. Lead: find what calls preventDefault on that stylus touchstart, or make the button act on the pointer lift like the other tool buttons.

## C0-4 Paste with a finger: Safari's own "Paste" bubble, then an error with a keyboard shortcut (item 1)

- **Saw:** the first one or two finger taps pasted. Then a small black "Paste" bubble appeared under the button, and the note "Your browser did not allow reading the clipboard. Press Ctrl+Shift+V (Cmd+Shift+V on a Mac) instead."
- **Expected:** a tap on Paste pastes.
- **What we know:** the "Paste" bubble is Apple's own permission bubble: Safari on the iPad allows a website to read the clipboard only after a tap on that bubble (from another app's copy). If it is not tapped, the app is refused. The note talks about a keyboard the owner does not use.
- **To decide:** the note on an iPad says "Tap Paste in the small bubble to allow it" (plain words, no keyboard shortcut); things copied inside our own app paste without the bubble (our own copy is kept in memory as well). Pictures not needed: text only.
