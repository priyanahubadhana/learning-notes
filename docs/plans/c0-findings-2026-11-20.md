## C0-1 The first box on a page ignores the owner's box style

- **Saw:** with the Text tool, tapping at the top of an empty page made a plain box (thin outline, no fill) right under the tabs.
- **Expected:** the same look as the owner's "Use for new boxes" style (filled, dashed border; owner screenshot 1, 18:19).
- **Lead (read in the code, not proven):** `addBox` applies the default style (`paper.boxStyleDefault`, src/paper/boxService.ts:102), but `addBoxInOrder` (same file, :414) does not, and the page's first box may be the page's own main box, which is never made by `addBox`. Owner's answers below decide which path it was.
- **Owner answers (20 Nov, 18:27):** a box made by tapping lower on an empty page gets the style; the box made by tapping at the top of the page (the page's own first box) does not. A box made with the + box icon, and a box made then pasted into from the box bar, looked the same as the plain one. Yes: every new box, the first one included, starts with the style. Yes: old pages keep their first box as it is (no repair of old notes).
- **Fix:** part C0-1 in lane B (`slice/c0-1-box-style`, ln-2a14), started 20 Nov; a test per way of making a box (tap, top of page, +, Enter, paste, phone order).
