# Smart selection bar — research (Opus, 19 Nov 2026)

Names (owner, 22 Nov 2026): this part is now called the Action bar (press-and-hold row: the Hold menu).

Owner ask: one premium bar for every selection (text, ink, pictures, mixed), customisable, with purpose presets editable in Settings. Look: our new text Action bar (premium, on-theme); features: today's Lasso bar (great features, poor look). Never drop a feature.

## What others do

- **Goodnotes:** the Lasso selects handwriting, pictures, text boxes and sticky notes; an "Included in selection" filter chooses which types it picks up; a selection opens an object menu whose items depend on the type (handwriting: convert to text or math, edit as text). Goodnotes 7 made the toolbar less customisable and reviewers disliked that. [support.goodnotes.com lasso article; beingpaperless.com Goodnotes 7 review]
- **Notability:** text is moved and resized with the Lasso; converted text drops in as a resizable box; the Lasso moves items only within a page (Goodnotes across pages). [paperlike.com 2026 comparison]
- **MyScript Notes (ex Nebo):** pen gestures edit text and diagrams directly. [goodnotes.com alternatives blog]
- **General guidance:** floating bars near the selection for content actions, fixed bars for global ones; show only relevant controls (context-driven); few primary controls on small screens; every item named for accessibility. [Material 3 toolbars; shadcn contextual toolbar; Strapi floating selection menu issue]

## Lessons for us

1. Context-driven: the bar's buttons follow the selection type (owner's Action bar). Matches Goodnotes' object menu and general guidance.
2. Keep it customisable (Goodnotes lost goodwill by removing this).
3. An "Included in selection" filter for mixed selections (text / ink / pictures) is a proven pattern.
4. Few primary buttons on the bar; the rest under ⋯ (phone especially).
5. Presets by purpose are rare in competitors: a chance to stand out.
