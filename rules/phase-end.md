# End of a Phase

- Check the phase's Definition of Done: all tests pass, security review done, owner visual checks passed.
- Summary of at most 10 lines.
- Full plain-language explanation of what was built, with examples; also save it into LEARNING.md (one section per phase) so the owner can reread it.
- Short retrospective, including suggested prompt improvements.
- Update all project files (README, CLAUDE.md, CHANGELOG, IDEAS, `rules/`).
