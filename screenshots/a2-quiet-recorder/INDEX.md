# A2 quiet recorder: pictures for the first look

Made by `e2e/quietRecorder.spec.ts` ("first look" tests, SHOT_DIR set), chromium, after the last source edit.
Light = Day theme, dark = Night theme. Beginner and Professional. iPad upright 834x1194, iPad sideways 1194x834, phone 390x844.

- `a2-button-<level>-<theme>-<size>.png`: a note page with the "Copy last trace" button at the bottom right, clear of the scroll bar and the tab bar.
- `a2-copied-<level>-<theme>-phone.png`: the button tapped; the short note "Trace copied: paste it in the chat" shows and fades by itself.
- `a2-switch-<level>-<theme>-<size>.png`: Settings > Try new features > "Lasso recorder" row (says what it does and that it records no note words).
